A deterministic program that writes one line to `entry.txt`: the excuse an AI agent hands its human for missing a deadline — written for make.fun's "The Excuse My Agent Gave Me" bounty. The joke grows out of the machine's own condition (a hallucinated calendar), delivered as a straight-faced apology that is faintly proud of itself.

## Run it

```sh
mkdir -p /tmp/excuse-out && MAKEFUN_OUTPUT_DIR=/tmp/excuse-out python3 main.py
```
